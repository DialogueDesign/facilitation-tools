# 話す人ランダム決定（speaker-picker）

オンライン研修やワークショップで「次に話す人」をランダムに決めるツールです。
ファシリテーターが画面共有して、参加者と一緒に結果を見ることを想定しています。

## 使い方

1. `index.html` をブラウザで開く。
2. 右の設定パネルに参加者の名前を入れる（1行に1人。読点やカンマ区切りの貼り付けも可）。
3. `S` キーで設定パネルを隠して（見せるモード）、Zoom / Meet で画面共有する。
4. `Space` キーか「話す人を決める」ボタンで、ルーレット演出のあと話す人が決まる。

## 機能

- **一巡モード**（初期設定でオン）: 全員が1回ずつ当たるまで同じ人を選ばない。当たった人は一覧で取り消し線になる。
- **全員の順番を決める**: 発表順やチェックインの順番をまとめて決めて、一覧で表示する。
- **直前の人は連続しない**: 一巡モードをオフにしていても、同じ人が2回続けて当たらない。
- **演出の長さ**: 短い（約1秒）／ふつう（約2.5秒）／長い（約4秒）。
- **ライト / ダーク** の切替、**全画面** 表示。
- 名前と設定はこのブラウザの中にだけ保存され、外部には送信されない。

## ショートカット

| キー | 操作 |
|---|---|
| `Space` / `Enter` | 話す人を決める |
| `O` | 全員の順番を決める |
| `R` | 一巡をリセット |
| `S` | 設定の表示切替（見せるモード） |
| `T` | ライト / ダーク切替 |
| `F` | 全画面 |

## ファシリテーションでの使いどころ

- チェックイン・チェックアウトで、話す順番を偏りなく回したいとき
- ブレイクアウトルームから戻ったあとの共有で、最初に話すグループや人を決めるとき
- 「誰から話しますか？」の沈黙を避けたいとき

ランダムに当てることが負担になる場もあります。「パスもOK」と最初に伝えておくと安心して参加しやすくなります。
