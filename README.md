# facilitation-tools

ファシリテーションや対話設計を支援する小さなAIツール集です。

Zoom や Google Meet などのオンライン研修で、ファシリテーターが画面共有して参加者に見せることを前提に作っています。
どのツールも HTML ファイル1つで完結していて、ダウンロードしてブラウザで開けばオフラインでも動きます。

## ツール一覧

| ツール | 内容 |
|---|---|
| [話す人ランダム決定（speaker-picker）](tools/speaker-picker/) | 参加者の名前からルーレット演出で話す人を決める。全員に一巡するまで重複なし、発表順をまとめて決めることも可能 |

## 使い方

1. 使いたいツールのフォルダにある `index.html` をダウンロードする。
2. ブラウザで開く。
3. Zoom / Meet で、そのブラウザのウィンドウ（またはタブ）を画面共有する。

各ツールの詳しい使い方は、それぞれのフォルダの README を見てください。
